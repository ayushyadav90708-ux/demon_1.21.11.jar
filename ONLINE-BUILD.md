# GitHub cloud build

1. Create a GitHub repository.
2. Upload all files in this project.
3. Open **Actions**.
4. Select **Build Heaven**.
5. Click **Run workflow**.
6. Open the completed run and download the artifact named `Heaven-Fabric-1.21.11`.
7. Put `heaven-1.1.0.jar` in your Fabric 1.21.11 `mods` folder.

The build runner installs Java 21 and Gradle in the cloud; nothing is installed locally.
